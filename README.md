# WaniKani Progress Tracker

A standalone browser app for tracking your WaniKani SRS progress between visits.

## Features

- Stores your WaniKani API token locally in your browser
- Tracks SRS level changes across your assignments
- Shows level-up and level-down changes since your last refresh
- Calculates overall WaniKani completion percentage
- Runs entirely in the browser with no server required

## Development

Install dependencies:

```bash
npm install
```

Run checks:

```bash
npm test
npm run lint
```

Open [index.html](./index.html) directly in a browser to use the app locally.
